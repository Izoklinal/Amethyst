# Оболочка приложения

Утверждённый план фазы 0. Выполнение сверяется с этим файлом. Документы в `docs/`, правила и `AGENTS.md` не меняются.

## Цель

Пустое окно: переключение светлой и тёмной темы и переход между тремя разделами. Status сохраняет проверку связи с Core. Explorer и Search не обращаются к файлам.

## Пункты

- [x] Семантические токены в `src/styles/global.css`: фон, поверхность, основной и вторичный текст, граница, акцент, `--spacing-1` … `--spacing-4`, радиус, ширина боковой колонки. Цвета темы через `[data-theme="light"]` и `[data-theme="dark"]`.
- [x] Скрипт в `index.html` ставит `data-theme` до загрузки React из сохранённого значения или `prefers-color-scheme`.
- [x] Модуль темы читает и записывает выбор в `localStorage` и выставляет атрибут.
- [x] `AppShell`: боковая колонка фиксированной ширины и основная область.
- [x] `Sidebar`: Status, Explorer, Search и переключатель Light / Dark. Выбранный раздел виден не только цветом.
- [x] `StatusView` показывает строку из Core.
- [x] `PlaceholderView` сообщает, что Explorer или Search ещё недоступен.
- [x] `App.tsx` только собирает оболочку. `App.module.css` удалён.
- [x] Состояние раздела не пишется на диск. Сохраняется только тема.
- [x] `npm run build` проходит.
- [x] В окне Status показывает `Amethyst 0.1.0`, разделы переключаются, обе темы меняют фон и текст, выбор темы переживает перезапуск.

## Вне шага

Vault, заметки, редактор, поиск по файлам, Git, вкладки, ресайзер, сохранение раскладки, сочетания клавиш, окно настроек, логирование, тестовый раннер фронтенда, новые зависимости, отдельные файлы токенов.
